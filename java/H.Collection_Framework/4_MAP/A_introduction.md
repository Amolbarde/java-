# MAP
- is use to store key-value pair. Each key must be unique, but value can be duplicate
- Does not allow duplicate key but values can be duplicate. 
- Allow single null as key and multiple null as value.
- A map is usefull when you want to associate a key (like a name or ID) with a value ( like an age or description).

# Common classes that implement MAP:
. HahsMap - fast and unordered
. TreeMap - sorted by key
. LinkedHashMap - ordered by insertion

- A HashMap can store many different combinations such as 
 
  . String keys and Integer values
  . String keys and String values
