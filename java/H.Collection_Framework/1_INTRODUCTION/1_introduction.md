# Collection :
- THe Collection in java is a framework that provide an architecture to store and manipulate the group of object. 
- The java collection framework provide set of interface and classes to implement various data structure and algorithm
- java collection can achive all the operation that you can perform on data such as searching, sorting, insertion, manipulation, and deletion 
- it means a single unit of object

- The Java Collections Framework provides a set of interfaces (like List, Set, and Map) and a set of classes (ArrayList, HashSet, HashMap, etc.) that implement those interfaces.
