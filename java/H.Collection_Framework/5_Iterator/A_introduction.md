# Iterator
- an iterator is an object used to access(traverse) the element of a collection one by one.
- its mainly used with 
  . ArrayList
  . LinkedList
  . HashSet
  . TreeSet
  . LinkedHashSet
  
# Example
 - imagine a book 
 you don't jump to every page randomnly.
 you read
 page1 -> page2 -> page3 -> page4

Iterator works the same way.

# Synrax

Iterator<DataType> it = list.iterator();
